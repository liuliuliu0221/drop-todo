# 水滴待办 Alpha 内测说明

## 安装

1. 打开 DMG；
2. 将“水滴待办”拖入 `Applications`；
3. 从“应用程序”启动；
4. 更新版本可直接覆盖旧应用，任务数据位于应用沙盒中，不应因覆盖安装被删除。

只有 Developer ID 签名且完成 Apple 公证的候选包可交给其他用户。标记为 `dry-run` 的 DMG 使用本机临时签名，仅供开发验证，不应绕过 Gatekeeper 对外分发。

## 反馈信息

反馈给分发者时请附上：版本与构建号、Mac 机型、macOS 版本、是否使用外接屏/全屏、复现步骤、期望结果和实际结果。设置页可以导出最近 7 天诊断日志；日志不包含任务名称。

涉及数据一致性时，除非用户明确同意，不应要求发送完整任务 JSON。
