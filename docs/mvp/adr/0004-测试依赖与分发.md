# ADR 0004：测试、依赖与分发

- 状态：已采纳
- 日期：2026-08-19

## 背景

MVP 需要控制第三方依赖与发布复杂度，同时覆盖领域、并发、窗口交互和性能风险。

## 决定

- 单元与集成测试使用 Swift Testing；UI 与性能测试使用 XCTest。
- 唯一第三方依赖为精确锁定的 `KeyboardShortcuts 3.0.1`，提交 `Package.resolved`。
- 开机启动使用原生 `SMAppService`，设置使用 UserDefaults 类型安全封装，日志使用 OSLog。
- 通过 Developer ID Application 签名、Apple Notarization 和 DMG 分发。
- MVP 采用手动覆盖安装，不加入 Sparkle，也不走 App Store。

## 影响

依赖升级必须独立评审。M4 发布流程需要验证签名、公证、Gatekeeper、覆盖安装数据保留和干净账户启动。

## 备选方案

曾考虑全部使用 XCTest、引入开机启动/设置封装及 Sparkle。当前系统框架和测试分工已经满足 MVP，增加依赖会扩大维护与发布面，因此未采纳。

## 回滚条件

只有系统框架无法满足明确需求，或手动更新已成为经验证的内测阻断项时，才评审新增依赖或更新机制。
