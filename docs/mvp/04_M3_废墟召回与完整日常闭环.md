# M3：废墟召回与完整日常闭环

## 1. 阶段目标

补齐逾期、废墟、召回、焚毁、已完成历史、设置和降级行为，使任务从创建到最终状态的所有路径闭环。

## 2. 工作包

### 2.1 M3A：在线到期快照与视觉协调

- `TimeEngine`、`expireDueTasks(at:)` 与生命周期 reconcile 已在 M1 完成，M3 不建立第二套状态机；
- 同时到期的在线任务返回有序动画快照；
- 启动或唤醒发现的历史逾期任务沿用 M1 规则直接校正，不补播动画；
- 在线同时到期动画设置并发/排队上限，避免动画风暴；
- 悬停保护只延迟对应的 expire 命令，不改变持久 deadline。

### 2.2 M3A：逾期坠落

- 状态先持久化为 ruined；
- renderer 使用 ExpirationSnapshot 播放约 0.6 秒拉长、断开和坠落；
- 多个在线同时到期动画间隔约 0.2 秒；
- 动画取消或 App 退出不恢复 active；
- 废墟显示原 deadline，逾期时长为 now - deadline；
- 不发送通知、不播放声音。

### 2.3 M3A：时间废墟

- 按原截止时间倒序或产品约定的稳定顺序展示；
- 展示名称、原截止时间和实时逾期时长；
- 每项提供召回交互和焚毁入口；
- 逾期时长低频刷新，不为每行创建独立 Timer；
- 空状态包含返回进行中入口。

### 2.4 M3B：连点 10 次召回

- 会话状态按 task ID 保存 clickCount 和 lastClickInstant；
- 点击其他任务或间隔超过 1 秒清零；
- 每次点击显示递增裂纹并触发触觉或视觉震动；
- 第 10 次展开与创建相同的时间选择器；
- 取消选择则清零并恢复普通废墟状态；
- 确认后在一个 TaskStore 事务中把旧记录设为 recalled，并创建新 active；
- 新任务继承标题、标签和紧急度，使用新的 id、createdAt、visualStartAt、deadline；
- 新任务记录 recalledFromID；
- 新旧两条记录必须同时成功或同时失败。

### 2.5 M3B：焚毁与关联

- 二次确认中明确无法恢复；
- 删除当前 ruined 记录；
- 不删除已召回产生的新任务；
- 若删除使新任务产生悬空 recalledFromID，则清除该字段；
- 删除和关联修复在单一 Store 事务完成。

### 2.6 M3C：已完成、设置和数据工具

- 已完成列表按 completedAt 倒序，只读；
- 清除完成记录和清除全部数据均二次确认；
- 设置完成：快捷键、开机启动、全屏隐藏、鱼缸显示/位置；
- 自动读取系统 Reduce Motion；
- 实现任务 JSON 和最近 7 天诊断日志导出；
- 导出通过 `NSSavePanel` 由用户选择目标位置，依赖 App Sandbox 的 User Selected File Read/Write 授权；
- 不实现导入和自动上传。

### 2.7 M3C：屏幕环境与能力暂停

- 外接显示器、镜像或合盖仅使用外接屏时暂停 NotchRenderPanel、HitPanels 和 HoverCard；
- 菜单栏显示未适配提示；
- 主窗口、任务计时和鱼缸继续工作；
- 恢复单屏后先 reconcile，再恢复水滴；
- 无刘海设备已由 M0 在启动时提示不受支持并退出；
- 全屏显示开关即时生效。

## 3. 关键事务测试

- expire：active → ruined 与动画中断；
- recall：旧 recalled + 新 active 的原子性；
- burn：删除旧记录且不删除后代；
- clear completed：不影响 active/ruined；
- clear all：主文件、历史和 previous 的边界；
- reconcile：跨越一个和多个 deadline；
- 保护期：截止后 59.9 秒可完成，60 秒后不可完成；
- 时间回拨、前拨和时区变化。

## 4. 手工场景

- 到期时应用前台、后台和全屏；
- 到期前睡眠、到期后唤醒；
- 同时到期 2、5、10 个任务；
- 召回第 9 次超时、第 10 次取消、确认失败；
- 焚毁存在后代的新旧关系；
- 外接显示器连接、镜像、断开；
- 无刘海 Apple Silicon Mac 的启动阻断提示；
- 导出数据和日志后检查隐私内容。

## 5. 退出条件

- [ ] 主动完成、取消、逾期、召回、焚毁全部闭环；
- [ ] 到期状态不依赖 App 持续运行；
- [ ] 召回事务不会产生半条记录；
- [ ] 睡眠和系统时间变化后 1 秒内校正；
- [ ] 多显示器暂停及恢复无残留窗口；
- [ ] 数据和日志可以主动导出；
- [ ] 默认日志不包含任务名称；
- [ ] POC 功能验收第 14.1～14.5 节全部通过；
- [ ] 无 P0/P1 缺陷。

## 6. 不在本阶段

- 自动更新；
- 自动崩溃上报；
- 多屏刘海渲染；
- 视觉精修之外的新功能；
- 正式签名和公证发布。

## 7. 2026-08-20 实现记录

### 7.1 M3A

- `TimeEngine` 区分在线定时触发与启动/唤醒校正，仅在线触发发送动画快照；
- 新增独立 `ExpirationOverlayPanel`，先持久化 ruined，再播放约 0.6 秒拉长和坠落；
- 同批动画按 deadline 排序，间隔 0.2 秒，单批最多播放 5 项；
- 时间废墟按原 deadline 倒序展示，使用一个低频 `TimelineView` 更新逾期时长。

### 7.2 M3B

- `RecallTapSession` 按 task ID 保存 10 连点进度，跨任务或间隔超过 1 秒重置；
- 第 10 次在行内展开新截止时间选择器，取消会清空裂纹状态；
- `TaskService.recall` 通过一次 Store 保存同时归档旧记录并创建带 `recalledFromID` 的新 active；
- `TaskService.burn` 在一次 Store 保存中删除废墟并清理后代悬空关联。

### 7.3 M3C

- 已完成列表保持只读和倒序，清除完成与清除全部均有二次确认；
- 设置包含快捷键、登录时启动、全屏隐藏、Reduce Motion 状态、鱼缸显示与位置；
- 支持导出任务 JSON 和最近 7 天诊断 JSON，保存目标由 `NSSavePanel` 选择；
- 多显示器、镜像和全屏暂停时，菜单栏同步显示暂停原因；主窗口、计时和鱼缸不停止。

### 7.4 自动化覆盖

- recall 原子性及重载；
- burn 保留后代并修复悬空关联；
- clear all 清理 previous 备份边界；
- 10 连点、超时和跨任务重置；
- 坠落动画拉长、落出屏幕与透明结束。
