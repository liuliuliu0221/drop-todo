# ADR 0001：平台、命名与工具链

- 状态：已采纳
- 日期：2026-08-19

## 背景

产品只面向带内置刘海屏的 Mac，需要统一 Xcode 模板遗留命名、最低系统和并发基线，避免进入功能开发后再做破坏性迁移。

## 决定

- 仓库目录使用 `Drop_todo`；project、app target、scheme 和 Swift module 使用 `WaterDropTodo`；显示名为“水滴待办”；Bundle ID 为 `com.liuliuliu.WaterDropTodo`。
- 建立 `WaterDropTodo`、`WaterDropTodoTests`、`WaterDropTodoUITests` 三个 Target。
- 最低系统为 macOS 13.0，仅构建 arm64，仅支持带内置刘海屏的 Apple Silicon MacBook。
- 使用 Swift 6 与 Strict Concurrency `Complete`；不设置全局默认 MainActor，UI/AppKit/窗口入口显式 `@MainActor`。
- 无刘海设备显示不受支持并退出；外接、镜像或合盖仅外接屏时只暂停刘海能力。

## 影响

M0 必须先完成工程重命名和配置审计。无刘海与 Intel 设备不进入业务主流程，也不承诺兼容。

## 备选方案

曾考虑继续使用模板名、支持无刘海降级和保留 Swift 5 模式；这些方案会扩大验收矩阵或把工程迁移推迟到功能开发后，因此未采纳。

## 回滚条件

只有产品范围正式扩展到无刘海或 Intel 设备，或目标系统能力要求提高时，才重新评审本决定。
