# ADR 0002：App Sandbox 与 JSON 持久化

- 状态：已采纳
- 日期：2026-08-19

## 背景

MVP 数据量小且完全本地，需要可靠、可检查、易备份的持久化，同时保留 Developer ID 分发下的最小权限边界。

## 决定

- 开启 App Sandbox 和 User Selected File Read/Write。
- 使用 `FileManager.applicationSupportDirectory` 在沙盒容器内定位数据目录，不硬编码绝对路径。
- 使用版本化 Codable JSON：`tasks.json` 与 `tasks.previous.json`。
- `TaskStore` actor 串行化访问，采用临时文件、原子替换与上一版备份。
- 数据与日志导出通过 `NSSavePanel` 获得用户选择位置的访问权。
- MVP 不使用 SQLite，也不实现导入。

## 影响

存储逻辑保持简单透明；写入失败、主文件损坏和备份恢复必须有自动化测试。任何文件访问都必须符合沙盒授权范围。

## 备选方案

曾评估 SQLite 与非沙盒 Developer ID 应用。MVP 查询规模不足以抵消数据库复杂度，非沙盒也会扩大文件访问边界，因此均未采纳。

## 回滚条件

只有数据规模、查询复杂度或一致性需求使 JSON 无法满足已测性能与可靠性门槛时，才重新评审存储方案。
