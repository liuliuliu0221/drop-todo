# 水滴待办隐私说明

水滴待办是一款本地优先的 macOS 待办应用。

- 任务标题、截止时间、标签、状态和设置默认只保存在本机应用沙盒内；
- 应用不创建账户，不包含广告、分析 SDK 或遥测，不会自动上传任务数据；
- 应用不请求通讯录、日历、相机、麦克风、位置、蓝牙、USB、屏幕录制、辅助功能或输入监控权限；
- 只有用户主动选择“导出任务 JSON”时，应用才会把任务数据写入用户选择的位置；
- 本地诊断日志保留最近 7 天，不包含任务名称，只有用户主动导出后才会离开应用沙盒；
- 全局快捷键由精确锁定的开源依赖 KeyboardShortcuts 提供，应用本身不监听或上传其他键盘输入；
- 删除应用不会自动删除其 Application Support 数据；需要彻底删除时，应先在设置中清除数据或手动移除应用沙盒数据。

当前内测构建没有联网功能。如未来加入任何网络能力，本说明和相关架构决策必须在发布前更新。
