# M1：任务数据与应用外壳

## 1. 阶段目标

建立不依赖刘海视觉也可以日常使用的任务与数据闭环：启动、创建、查看、编辑、完成、取消、重启恢复。M1 结束时，业务核心必须可测试且不能依赖动画回调。

## 2. 前置条件

- M0 全部退出条件通过；
- WindowCoordinator 和测试 Target 可用；
- 核心窗口架构不再变更。

## 3. 工作包

### 3.1 M1A：领域、存储与时间正确性

- 实现 TaskRecord、TaskStatus、TaskTag、Urgency；
- 实现 CreateTaskInput、TaskChanges 和领域错误；
- 实现 TaskService 的 create、update、complete、cancel、expireDueTasks；
- 建立 `StoreEnvelope(schemaVersion: 1)`；
- 实现 TaskStore actor、原子写入和 previous 备份；
- 首次启动没有文件时创建空 Store；
- 主文件损坏时尝试 previous，恢复前保留损坏文件；
- 测试使用临时目录，不写用户 Application Support。

时间正确性基线：

- `TimeEngine` 根据最近 deadline 安排单次唤醒，不使用永久轮询；
- 启动、睡眠唤醒、应用重新激活、系统时间变化和时区变化后执行 reconcile；
- 持久化绝对 `Date`，自然日预设只在输入时通过 `Calendar` 解析；
- deadline 到达后由领域命令将 `active → ruined` 并持久化，随后从 active 快照移除；
- M1 只提供废墟计数与占位入口，不实现坠落动画或废墟视觉；
- 离线期间已到期的任务在 reconcile 时直接修正状态，不补播历史动画。

领域不变量：

- 标题 trim 后 1～100 字符；
- 新截止时间至少晚于命令执行时间 1 分钟；
- 只有 active 可以编辑、完成或取消；
- complete 必须先持久化，再返回动画快照；
- cancel 删除记录，不制造完成或废墟状态。

### 3.2 M1A：时间选项

实现纯函数 `DeadlinePresetResolver`：

| 选项 | 行为 |
|---|---|
| 30 分钟后 | 以选择时刻加 30 分钟 |
| 1 小时后 | 加 1 小时 |
| 2 小时后 | 加 2 小时 |
| 今晚 20:00 | 当天 20:00 前可用，之后不可用 |
| 明天 09:00 | 下一个自然日 09:00 |
| 自定义 | 分钟精度，最终统一走领域校验 |

跨日和夏令时计算使用 Calendar，不手算秒数拼装自然日。

### 3.3 M1B：应用外壳

- AppDelegate 创建 AppEnvironment；
- 使用 NSStatusItem 建立可控的菜单栏入口；
- 创建标准主窗口和设置打开逻辑；
- 关闭主窗口不退出应用；
- 首次启动欢迎页只出现一次；
- 后续启动只显示状态栏和鱼缸占位；
- 菜单包含新建、主窗口、鱼缸显示/调整、设置和退出；
- 菜单展示 active 总数和最近截止时间。

### 3.4 M1B：全局快捷键与快速创建

- 仅引入并锁定 `KeyboardShortcuts 3.0.1`，注册默认 `⌥T`；
- 支持录制和冲突错误展示；
- 已打开时只聚焦同一个 QuickCapturePanel；
- 事件和时间分离；
- 默认紧急度中、默认无标签、默认无时间；
- 完整键盘导航：Tab、方向键、Enter、Esc；
- 校验错误内联展示；
- 成功创建后等待持久化成功再关闭；
- 写入失败时保留用户输入并显示错误。

### 3.5 M1C：主窗口与任务管理

本阶段实现：

- 进行中列表，按 deadline 升序；
- 标签筛选；
- 编辑 Sheet；
- 完成；
- 二次确认后取消；
- 已完成只读列表；
- 二次确认清除完成记录；
- 设置页基础框架。

时间废墟页显示真实 ruined 数量和占位列表入口；完整废墟视觉与召回交互在 M3。

### 3.6 M1C：本地日志与可靠性

- 建立 app、store、time、window 分类；
- 记录任务 ID 和状态，不记录标题；
- 记录 Store 恢复和写入错误；
- 提供 Debug 环境日志查看入口，正式导出在 M3。

## 4. 测试

### 4.1 单元测试

- 所有标题、截止时间和非法状态边界；
- 六种时间选项，包括 19:59、20:00、月末和跨年；
- create/update/complete/cancel 状态；
- 排序和标签筛选；
- JSON 往返、未知字段兼容和损坏恢复；
- 并发提交时没有丢写。
- 最近 deadline 单次调度、到期状态转换和重复执行幂等；
- 启动/唤醒/重新激活/系统时间与时区变化后的 reconcile；
- 离线跨过截止时间后直接修正状态且不补播动画。

### 4.2 集成/UI 测试

- 首次启动与后续启动；
- `⌥T` 打开和重复聚焦；
- 纯键盘创建；
- 创建失败不清空输入；
- 编辑后排序变化；
- 完成与取消确认；
- 强制退出后恢复。

## 6. 退出条件

- [ ] 不显示刘海时也能完成创建、编辑、完成和取消；
- [ ] 100 次混合业务操作无数据丢失；
- [ ] 20 次强退和重启数据一致；
- [ ] 主文件损坏可从 previous 恢复；
- [ ] 快速创建可完全键盘操作；
- [ ] 完成状态在动画之前持久化；
- [ ] 到期和 reconcile 后不存在 deadline 已过但仍为 active 的陈旧任务；
- [ ] 默认日志不包含任务名称；
- [ ] 无 P0/P1 缺陷。

## 7. 不在本阶段

- 正式刘海渲染和悬停卡；
- 完成飞行动画和鱼缸反馈；
- 逾期坠落视觉、废墟正式界面、召回和焚毁；
- 多显示器及全屏最终策略；
- 正式分发包。
