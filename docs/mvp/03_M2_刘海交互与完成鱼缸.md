# M2：刘海交互与完成鱼缸

## 1. 阶段目标

把 M1 的真实任务接入刘海液池，完成“创建 → 持续感知 → 悬停查看 → 主动完成 → 汇入鱼缸”的核心产品路径。

## 2. 前置条件

- M1 数据闭环通过；
- M0 Metal、命中 Panel 和过渡窗口方案成立；
- 任务状态由 TaskService 单一管理。

## 3. 工作包

### 3.1 M2A：DisplayPolicy

输出单一展示决策：

```swift
enum NotchVisibilityReason {
    case visible
    case unsupportedNoNotch
    case multipleDisplays
    case mirroredDisplay
    case hiddenByFullscreenPreference
}
```

- 单屏刘海设备返回 visible；
- 任意外接显示器或镜像时暂停刘海窗口；
- 无刘海是 M0 已处理的启动阻断条件，不进入此运行时策略；
- 外接显示器、镜像或合盖仅使用外接屏时暂停刘海能力，但主应用继续运行；
- 全屏默认显示，设置开启后隐藏；
- 策略变化时由 WindowCoordinator 统一创建、隐藏和恢复窗口；
- 恢复显示前先调用 TimeEngine reconcile。

### 3.2 M2A：可见集合与布局

- 从 active 任务中按 deadline 升序取前 8；
- 对每项计算 `deadline - now`，按 24h、12h、6h、3h、1h、30min 边界映射七档固定颜色；
- 颜色不读取 `visualStartAt`，更靠右的任务只能同色或更深；
- 可见任务按 deadline 降序从左到右排列，越靠右一定越早到期；
- 任务 ID 生成稳定的非等距间隔，相邻中心最少约 19pt，每秒刷新不改变位置；
- 当前机型渲染框相对实体刘海左缩 2pt、右缩 1pt，有效宽度 177pt；
- 重要程度只影响液滴纵向长度，低/中/高目标约为 10/18/25pt，不影响位置或颜色；
- 三档纵向椭圆共用顶部连接点，renderer 根据半长度反算中心 Y，短水滴不得与液面分离；
- 水平半径按可见任务数量分档缩小，悬停命中范围保持不变；
- 悬停时水平半径与纵向长度放大到 2.0 倍，固定任务身份，避免邻近任务抢占悬停；
- 输出不可变 `NotchLayoutSnapshot`；
- renderer 和 hit panels 必须消费同一 Snapshot；
- 正在悬停或锁定的任务在交互结束前固定身份；
- 可见集合变化只做淡入淡出。

关键测试：0、1、3、5、8、9 个任务，相同截止时间，不同重要程度，七档颜色边界以及开始时间不影响颜色。

### 3.3 M2A：Metal 正式接入

- 将 M0 shader 参数绑定真实布局；
- 实现浅蓝、深蓝、沥青颜色曲线；
- 实现液面与 8 水滴连续连接；
- 实现悬停放大、光晕和连接保持；
- 把材质参数集中到 `LiquidTheme`，不散落魔法数字；
- Debug 可显示 FPS、帧时间、命中区和 task ID；Release 关闭；
- 无水滴、隐藏、睡眠时暂停渲染。

### 3.4 M2B：悬停和卡片保护

实施状态（2026-08-20）：已完成首轮开发并通过自动化测试，待实机交互验收。

交互状态机：

```text
idle
 → hoverPending(150ms)
 → presented
 → pinned
 → expiringGrace(max 60s)
 → closed / completed / expired
```

- 最近中心规则解决重叠命中；
- 卡片优先右侧，越界时左侧；
- 卡片 Panel 包含透明交互走廊；
- 离开完整交互区域 250ms 后关闭；
- 点击水滴进入 pinned；
- 外部点击或 Esc 解锁；
- 同时只允许一个 Card Session；
- 卡片只显示信息和“完成”；
- 倒计时显示快照冻结，持久 deadline 不改变；
- 保护时长使用单调时钟；
- 截止后保护期内仍可完成；超过 60 秒禁用完成，退出卡片后到期。
- `TimeEngine` 始终拥有到期状态转换权；Hover Session 只延迟这一次到期命令的执行，不建立第二套时间状态机。

### 3.5 M2C：完成事务与动画

实施状态（2026-08-20）：已完成首轮正式接入，待实机动画与鱼缸交互验收。

完成顺序：

1. 捕获动画源坐标和鱼缸目标坐标；
2. 调用 TaskService.complete；
3. 持久化成功后立即从 active 快照移除；
4. 使用返回的 CompletionSnapshot 播放临时水滴；
5. 动画结束只清理视觉资源，不再次改变领域状态。

来源规则：

- 悬停卡完成：从刘海水滴中心开始；
- 列表完成：从任务行转换后的屏幕坐标开始；
- 鱼缸隐藏：源位置淡出；
- 系统减少动态：源位置淡出，鱼缸仅轻微高亮；
- 正常模式：0.6～0.9 秒直线飞向鱼缸水面。

### 3.6 M2C：鱼缸

实施状态（2026-08-20）：正式 180×110pt 鱼缸、三鱼低频动画、隐藏/调整及位置持久化已接入。

- AquariumPanel 默认 `180 × 110pt`、主屏右下角 16pt；
- 默认显示、点击穿透、不成为 key window；
- “调整鱼缸位置”切换到可拖动模式，完成后重新点击穿透；
- 位置保存为显示器标识、归一化位置和最后有效绝对位置；
- 位置越界时约束到 visibleFrame；
- 固定三条鱼，不接受选择或点击；
- 平时 8～12fps 低频缓慢运动；
- 水滴落入时最近的鱼临时提速约 1 秒；
- 完成后恢复低频；
- 隐藏、睡眠时停止刷新。

## 4. 测试

### 4.1 自动化

- 七档剩余时间颜色的上下边界和从左到右单调性；
- 8 水滴布局约束和稳定身份；
- 卡片状态机的 150ms、250ms、60s 边界；
- 完成先写入后动画；
- 鱼缸隐藏和 Reduce Motion 分支；
- 坐标转换使用注入几何的单元测试。

### 4.2 实机

- 8 个水滴逐个悬停和锁定；
- 透明区域点击下层菜单栏；
- 悬停跨越截止时间；
- 卡片左右换边和交互走廊；
- 从刘海、列表直线飞入鱼缸；
- 动画中切换应用和退出；
- 调整、隐藏和恢复鱼缸；
- 系统减少动态效果；
- 30 分钟稳态能耗。
